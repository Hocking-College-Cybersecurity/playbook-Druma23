My prototype is a file organizer that will automatically sort files into folders based on the
file name. When in a designated folder it makes sub folders based on the month to organize it
even further. I included a dry-run mode to allow me to test the script without making changes
and make sure my script functioned properly. The exception handling keeps my prototype from
crashing if a file cannot be moved and just throws an error. The next steps I would take to make
it even better would be instead of moving folders with less than 3 files into a misc folder I’d
rather just put files that do not match any category into a miscellaneous folder. This would keep
the miscellaneous folder from becoming too disorganized. When doing my dry run I realized if
there was only one file in each they would all move into the miscellaneous folder which would
defeat the purpose of my organizer. The other idea to make my script better would be to add a
loop so the script automatically runs every so many days instead of having to do it manually.
This would be easier than using an external scheduler.
